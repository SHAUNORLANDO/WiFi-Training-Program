# WiFi Training Program – Module 6
## Wi-Fi Security Concepts

---

### 1. What are the pillars of Wi-Fi security?

Wi-Fi security is mainly based on three core pillars:

- Confidentiality  
  Ensures that data is protected from unauthorized access (encryption)

- Integrity  
  Ensures that data is not modified during transmission

- Availability  
  Ensures that network services are accessible when needed

Some also include:
- Authentication (verifying identity)
- Authorization (granting access)

---

### 2. Explain the difference between authentication and encryption in WiFi security.

Authentication:
- Verifies the identity of the user/device
- Example: entering WiFi password

Encryption:
- Protects the data being transmitted
- Converts data into unreadable format

Difference:

- Authentication → "Who are you?"
- Encryption → "Let me protect your data"

Both are required for secure communication.

---

### 3. Explain the differences between WEP, WPA, WPA2, and WPA3.

**WEP (Wired Equivalent Privacy):**
- Oldest security standard
- Uses weak encryption (RC4)
- Easily hackable

**WPA (Wi-Fi Protected Access):**
- Introduced as improvement over WEP
- Uses TKIP encryption
- More secure than WEP but still outdated

**WPA2:**
- Uses AES encryption (strong)
- Widely used standard
- Supports 4-way handshake

**WPA3:**
- Latest and most secure
- Uses SAE (Simultaneous Authentication of Equals)
- Protects against brute force attacks
- Better encryption and forward secrecy

Summary:
WEP < WPA < WPA2 < WPA3 (in terms of security)

| Std  | Cipher (C) | Integrity (I) | Authentication (A) | Weakness |
|------|-------------|----------------|---------------------|-----------|
| WEP  | RC4 | CRC32 | Shared Key | Key reuse, IV weakness |
| WPA  | RC4 + TKIP | MIC | Open Authentication + 4-Way Handshake | TKIP vulnerabilities, depends on password strength |
| WPA2 | AES-CCMP | CBC-MAC | Open Authentication + 4-Way Handshake | More secure than WPA, but vulnerable to weak passwords |
| WPA3 | AES-SAE | SHA | PMF + 4-Way Handshake | Most secure (currently) |

---

### 4. Why is WEP considered insecure compared to WPA2 or WPA3?

WEP is insecure because:

- Uses weak RC4 encryption
- Uses static keys (do not change)
- Small initialization vector (IV) → easy to crack
- Vulnerable to replay and brute force attacks

Result:
- Can be hacked within minutes

WPA2 and WPA3:
- Use stronger encryption (AES)
- Dynamic key generation
- Much harder to break

---

### 5. Why was WPA2 introduced?

WPA2 was introduced to fix the weaknesses of WEP and WPA.

Reasons:
- WPA still had vulnerabilities (TKIP issues)
- Needed stronger encryption method

Improvements in WPA2:
- Uses AES encryption
- Provides better data protection
- Supports robust key management

Result:
- Became the industry standard for many years

### 6. What is the role of the Pairwise Master Key (PMK) in the 4-way handshake?

PMK (Pairwise Master Key) is the base key used in the 4-way handshake.

Role:
- Derived from the WiFi password (passphrase)
- Used to generate PTK (Pairwise Transient Key)

Purpose:
- Ensures both client and AP share a common secret
- Helps in generating session-specific encryption keys


**Password → PMK → PTK → Secure communication**

---

### 7. How does the 4-way handshake ensure mutual authentication between the client and the access point?

The 4-way handshake ensures both client and AP prove they have the same PMK.

Process:
- AP sends ANonce
- Client generates SNonce
- Both calculate PTK independently
- Client sends MIC (Message Integrity Code)
- AP verifies MIC

If both match:
- Both sides confirm they have correct credentials

Result:
- Mutual authentication is achieved
- Secure keys are established

---

### 8. What will happen if we put a wrong passphrase during a 4-Way handshake?

If the passphrase is wrong:

- PMK generated by client will be incorrect
- PTK will not match with AP
- MIC verification will fail

Result:
- Handshake fails
- Connection is rejected
- User cannot connect to WiFi

### 9. What problem does 802.1X solve in a network?

802.1X solves the problem of secure authentication in networks.

Problem:
- Pre-shared passwords (PSK) are not scalable
- Difficult to manage in large networks

Solution:
- Uses centralized authentication (RADIUS server)
- Provides per-user authentication

Benefits:
- Better access control
- Scalable for enterprise networks

---

### 10. How does 802.1X enhance security over wireless networks?

802.1X improves security by:

- Using individual user authentication (username/password or certificates)
- Dynamic key generation (not shared keys)
- Integration with RADIUS server

Process:
- Client requests access
- Authentication server verifies identity
- Secure keys are generated

Advantages:
- Stronger security than PSK
- Prevents unauthorized access
- Suitable for enterprise environments
